# 作业文件批量整理脚本

一个批量整理作业文件的小脚本。按需求分阶段实现，每个阶段一个 PR。

| 阶段 | 需求 | 状态 |
| --- | --- | --- |
| 1 | 扫描与列出：列出文件的大小和修改时间，支持按扩展名过滤 | ✅ 已完成 |
| 2 | 批量改名：先预览再确认，处理重名冲突 | ✅ 已完成 |
| 3 | 归档与报告：按学期/类别移动文件，生成报告，支持撤销 | ✅ 已完成 |
| 4 | 改名规则可配置：用正则（`--rule` / `--rules`）自定义改名 | ✅ 已完成 |

## 环境要求

Python 3.10+（用到 `list[str] | None` 这类写法），只依赖标准库，无需安装第三方包。

## 用法

脚本有四个子命令：`list`（需求 1）、`rename`（需求 2、4）、`archive` / `undo`（需求 3）。

不写子命令时按 `list` 处理，所以下面两种写法等价：

```bash
python main.py D:/homework -e pdf
python main.py list D:/homework -e pdf
```

### 需求 1：扫描与列出

```bash
# 列出当前文件夹（含子文件夹）的所有文件
python main.py

# 列出指定文件夹
python main.py D:/homework

# 只看 .docx 和 .pdf（可重复写 -e，大小写不敏感，写 pdf / .pdf / *.pdf 都行）
python main.py D:/homework -e docx -e pdf
```

输出示例：

```
       6 B  2026-10-05 01:48:52  a.docx
      11 B  2026-10-05 01:48:52  b.pdf
       2 B  2026-10-05 01:48:52  sub\c.PDF

共 3 个文件，合计 19 B
```

每行依次是：大小（自动换算 B/KB/MB/GB）、修改时间、相对扫描目录的路径。
扫描是递归的；找不到文件或路径不是文件夹时打印提示并以退出码 1 结束。

### 需求 2：批量改名

默认把「学号_姓名_作业名.ext」改成「作业名_学号.ext」（规则本身可以换，见[需求 4](#需求-4改名规则可配置用正则)）。

```bash
# 先看会改成什么样，再决定要不要改（会问一句 y/N）
python main.py rename D:/homework

# 只看 .pdf；-y/--yes 表示不询问，直接执行
python main.py rename D:/homework -e pdf -y
```

输出示例：

```
将要改名 2 个文件：
  2023001_张三_作业一.pdf  ->  作业一_2023001.pdf
  2023002_李四_实验_report.docx  ->  实验_report_2023002.docx

跳过 1 个文件：
  随手记.txt：没有规则匹配

确认执行上面 2 个改名？[y/N]
```

几个约定：

- **不允许直接改**：默认只打印预览，必须回答 `y` 才真的改；回答别的（或直接回车）就取消，一个文件都不动。脚本里要免交互时用 `-y`。
- **重名不覆盖**：新名字已经被别的文件占用（包括本次别的文件要改成的名字、以及只在大小写上不同的名字）时，自动加序号，例如 `作业一_2023001_1.pdf`，并在预览里标出「重名，自动加了序号」。
- **默认规则下作业名里可以有下划线**：`2023002_李四_实验_report.docx` 会取第 3 段起的全部作为作业名。
- 不符合默认规则的文件会被跳过，并在预览里写明原因；跳过的文件保持原样。

### 需求 3：归档与报告

```bash
# 按学期归类（默认，由文件的修改时间推算：2~7 月算春季、8 月到次年 1 月算秋季）
python main.py archive D:/homework

# 按类别归类（类别就是扩展名，没有扩展名的进「其他」）
python main.py archive D:/homework --by category

# 只整理 .pdf；-y/--yes 表示不询问，直接执行
python main.py archive D:/homework --by term -e pdf -y

# 撤销上次归档
python main.py undo D:/homework
```

输出示例：

```
将要移动 3 个文件：
  a.pdf  ->  2026春\a.pdf
  b.pdf  ->  2026秋\b.pdf
  c.docx  ->  2026秋\c.docx

确认执行上面 3 个移动？[y/N] y

已移动 3 个，跳过 0 个
报告：整理报告-20261005-015356.txt（用 python main.py undo D:/homework 可以撤销）
```

几个约定：

- **跟改名一样先预览再确认**，回答 `y` 才真的移动；`-y` 供脚本免交互使用。
- **报告**写在待整理文件夹里，文件名形如 `整理报告-20261005-015356.txt`，内容包括归类方式、每个文件从哪移到哪、跳过哪些及原因、各子文件夹各有多少个。
- **不覆盖**：目标子文件夹里已有同名文件、或本次别的文件要移到同一位置时，跳过并写明原因；已经在正确子文件夹里的文件也会跳过，所以重复执行是安全的。
- **撤销**：每次归档会把移动记录写到该文件夹下的 `.pdd03_last_archive.json`，`undo` 读它把文件移回原位（同样先预览再确认），完成后删掉日志并清理空子文件夹。原位置已有同名文件、或文件已被移走的条目会跳过并写明原因。撤销只针对上一次归档，不能连续撤销两次。
- 扫描会忽略隐藏文件和脚本自己生成的报告/日志，不会被再次整理。

### 需求 4：改名规则可配置（用正则）

改名规则是一张「正则 => 替换模板」的规则表：正则整段匹配文件名（不含扩展名），替换模板用 `\g<分组名>` 引用捕获到的内容。脚本带一条内置默认规则，不给规则时用的就是它，所以不加参数的行为和需求 2 一样。

```bash
# 自定义规则：把「学号_姓名_作业名.pdf」改成「作业名[学号].pdf」
python main.py rename D:/homework --rule '^(?P<sid>\d+)_(?P<name>[^_]+)_(?P<hw>.+)$=>\g<hw>[\g<sid>]'

# 多条规则：可重复写 --rule，写在最左边的先试
python main.py rename D:/homework \
  --rule '^(?P<sid>\d+)_(?P<name>[^_]+)_(?P<hw>.+)$=>\g<hw>_\g<sid>' \
  --rule '^IMG_(?P<n>\d+)$=>照片_\g<n>'

# 也可以把规则写进 JSON 配置文件
python main.py rename D:/homework --rules my_rules.json
```

配置文件格式（`ext` 可选，相当于默认的 `-e`；命令行里写了 `-e` 就以命令行为准）：

```json
{
  "rules": [
    { "pattern": "^(?P<sid>\\d+)_(?P<name>[^_]+)_(?P<hw>.+)$", "replace": "\\g<hw>_\\g<sid>" }
  ],
  "ext": ["pdf", "docx"]
}
```

几个约定：

- 规则按顺序试，第一个整段匹配上的生效；优先级是「命令行 `--rule` > 配置文件 > 内置默认」。有多条规则时，预览里会标出命中的是第几条。
- 正则会先编译检查：正则写错、或替换模板里引用了不存在的分组（`\g<名字>` / `\1`）时直接报错退出（退出码 2），不会动任何文件。
- 预览、确认、重名自动加序号、跳过并写明原因这些行为，和需求 2 完全一致。
