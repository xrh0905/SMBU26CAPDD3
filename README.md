# 作业文件批量整理脚本

一个批量整理作业文件的小脚本。整体分三个阶段实现，每个阶段一个 PR。

| 阶段 | 需求 | 状态 |
| --- | --- | --- |
| 1 | 扫描与列出：列出文件的大小和修改时间，支持按扩展名过滤 | ✅ 已完成 |
| 2 | 批量改名：先预览再确认，处理重名冲突 | ✅ 已完成 |
| 3 | 归档与报告：按学期/类别移动文件，生成报告，支持撤销 | ⏳ 待实现 |

## 环境要求

Python 3.10+（用到 `list[str] | None` 这类写法），只依赖标准库，无需安装第三方包。

## 用法

脚本有四个子命令：`list`（需求 1）、`rename`（需求 2），`archive` / `undo`（需求 3）。

不写子命令时按 `list` 处理，所以下面两种写法等价：

```bash
python main.py D:/homework -e pdf
python main.py list D:/homework -e pdf
```

### 需求 1：扫描与列出

```bash
# 列出当前文件夹（含子文件夹）的所有文件
python main.py

# 列出指定文件夹
python main.py D:/homework

# 只看 .docx 和 .pdf（可重复写 -e，大小写不敏感，写 pdf / .pdf / *.pdf 都行）
python main.py D:/homework -e docx -e pdf
```

输出示例：

```
       6 B  2026-10-05 01:48:52  a.docx
      11 B  2026-10-05 01:48:52  b.pdf
       2 B  2026-10-05 01:48:52  sub\c.PDF

共 3 个文件，合计 19 B
```

每行依次是：大小（自动换算 B/KB/MB/GB）、修改时间、相对扫描目录的路径。
扫描是递归的；找不到文件或路径不是文件夹时打印提示并以退出码 1 结束。

### 需求 2：批量改名

改名规则：把「学号_姓名_作业名.ext」改成「作业名_学号.ext」。

```bash
# 先看会改成什么样，再决定要不要改（会问一句 y/N）
python main.py rename D:/homework

# 只看 .pdf；-y/--yes 表示不询问，直接执行
python main.py rename D:/homework -e pdf -y
```

输出示例：

```
将要改名 2 个文件：
  2023001_张三_作业一.pdf  ->  作业一_2023001.pdf
  2023002_李四_实验_report.docx  ->  实验_report_2023002.docx

跳过 1 个文件：
  随手记.txt：文件名不是「学号_姓名_作业名」

确认执行上面 2 个改名？[y/N]
```

几个约定：

- **不允许直接改**：默认只打印预览，必须回答 `y` 才真的改；回答别的（或直接回车）就取消，一个文件都不动。脚本里要免交互时用 `-y`。
- **重名不覆盖**：新名字已经被别的文件占用（包括本次别的文件要改成的名字、以及只在大小写上不同的名字）时，自动加序号，例如 `作业一_2023001_1.pdf`，并在预览里标出「重名，自动加了序号」。
- **作业名里可以有下划线**：`2023002_李四_实验_report.docx` 会取第 3 段起的全部作为作业名。
- 不符合「学号_姓名_作业名」三段格式的文件会被跳过，并在预览里写明原因；跳过的文件保持原样。
